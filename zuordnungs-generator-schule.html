Zuordnungs-Generator der Emil-Petri-Schule Arnstadt

Karten eintragen, die zusammengehören. Daraus entsteht ein fertiges Klebespiel oder Memory für die Schüler.

1Aussehen

2Runden und Karten

In jede Zeile kommen die Karten, die zusammengehören. Im Spiel werden alle Karten einer Runde gemischt.
Statt Text kann eine Karte auch ein Bild zeigen: auf 🖼 tippen.
Über jeder Spalte kann man Vorlesen einstellen. Dann liest das Spiel die Karten dieser Spalte beim Antippen vor.
Tipps: 3/4 wird als Bruch angezeigt. * wird zum Malpunkt. Kurze Texte passen am besten auf die Karten.

4Spiel erstellen

„Spiel herunterladen“ speichert das fertige Spiel sofort als HTML-Datei, auf dem iPad in der App „Dateien“, am PC im Ordner „Downloads“. Die Datei kann man per Doppelklick im Browser öffnen, verschicken oder bei GitHub Pages hochladen. Um ein Spiel später zu ändern, öffne die Datei hier mit „Gespeichertes Spiel bearbeiten“.
