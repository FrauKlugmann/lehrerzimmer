Sortier-Generator der Emil-Petri-Schule Arnstadt

Körbe anlegen und Karten eintragen. Daraus entsteht ein fertiges Sortierspiel für die Schüler.

1Aussehen

2Runden, Körbe und Karten

Jede Runde hat 2 bis 4 Körbe. Unter jeden Korb kommen die Karten, die hineingehören. Im Spiel werden alle Karten einer Runde gemischt.
Statt Text kann eine Karte auch ein Bild zeigen: auf 🖼 tippen. Mit Vorlesen liest das Spiel die Karten beim Antippen vor.
Tipps: 3/4 wird als Bruch angezeigt. * wird zum Malpunkt. Höchstens 16 Karten pro Runde, damit alles auf das iPad passt.

4Spiel erstellen

„Spiel herunterladen“ speichert das fertige Spiel sofort als HTML-Datei, auf dem iPad in der App „Dateien“, am PC im Ordner „Downloads“. Die Datei kann man per Doppelklick im Browser öffnen, verschicken oder bei GitHub Pages hochladen. Um ein Spiel später zu ändern, öffne die Datei hier mit „Gespeichertes Spiel bearbeiten“.
